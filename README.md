# Film Platformu 🎬

Film Platformu, kullanıcıların film arayıp detaylarına ulaşabildiği, film bilgilerini gösteren basit bir web uygulamasıdır.  
Amacı: film arama + listeleme + detay görüntüleme gibi temel sinema sitesi işlevlerini sağlayarak hem frontend hem backend becerilerimi sergilemek.

## 🔎 Özellikler (Features)
- Film arama 
- Film listesi görüntüleme  
- Film detaylarına erişim 
- Responsive / mobil uyumlu tasarım  
- Kullanılan modern web teknolojileri  

## 🛠️ Kullanılan Teknolojiler (Tech Stack)
- HTML / CSS / JavaScript  
- (Backend / Frontend ) 
- (Css framework)

- Bu projede:

- API üzerinden veri çekme

- Kullanıcı arayüzü geliştirme

- Responsive tasarım
